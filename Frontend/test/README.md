# Frontend Test Directory

Ushbu papka Frontend (Next.js / React) loyihasi uchun unit testlar va UI komponent testlarini o'z ichiga oladi.

## Fayllar tuzilishi
- `example.test.ts` — Yordamchi funksiyalar (utilities), formatters va holat (state) boshqaruvini tekshirish uchun unit testlar.
- `components.test.tsx` — UI komponentlari va render holatlarini tekshirish uchun namunaviy test fayli.

## Test kutubxonalari
- **Jest / Vitest** — Unit testlar uchun
- **React Testing Library** — React komponentlarini render qilish va tekshirish uchun
